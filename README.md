# Workshop Campaign WATI — downloads

Ready-to-run versions of **Workshop Campaign WATI**, a small app for sending WhatsApp campaigns through WATI.
Installed copies check this page for new versions and update themselves (**Update now** in the app).

## Download the latest version

- **Windows:** [Workshop-Campaign-WATI.exe](https://github.com/Nandakumar23/workshop-campaign-wati-releases/releases/latest/download/Workshop-Campaign-WATI.exe)
- **Mac (Intel, also runs on Apple Silicon):** [Workshop-Campaign-WATI-mac-x86_64.zip](https://github.com/Nandakumar23/workshop-campaign-wati-releases/releases/latest/download/Workshop-Campaign-WATI-mac-x86_64.zip)

These links always give the newest version. All versions: [Releases](https://github.com/Nandakumar23/workshop-campaign-wati-releases/releases).

## First time

- **Windows:** double-click the downloaded file, then click **Add to Desktop** in the app.
- **Mac:** unzip, drag the app into **Applications**, then right-click it → **Open** → **Open**.

After that, the app tells you when a new version is out and updates itself.

Each release has a `latest.json` with the size and SHA-256 of every file; the app checks both before installing.
